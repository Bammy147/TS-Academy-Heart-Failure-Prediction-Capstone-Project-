Heart Failure Prediction – TS Academy Group 38 Capstone Project

Project Overview

This project is a Data Science capstone project completed as part of the TS Academy Data Science training programme. It focuses on applying machine learning techniques to a heart failure prediction dataset to explore patterns in clinical data and develop a predictive model.

The project demonstrates the application of data analysis, data preprocessing, exploratory data analysis (EDA), and machine learning to a healthcare-related classification problem.

Project Type: Machine Learning / Healthcare Analytics
Programme: TS Academy – Data Science
Project Group: Group 38
Author: Bamijoko Olubunmi Daniel

Objectives

The main objectives of this project are to:

- Explore and understand a heart failure-related dataset.
- Perform data cleaning and preprocessing.
- Conduct exploratory data analysis to identify patterns and relationships.
- Prepare relevant features for machine learning.
- Build and evaluate a classification model for heart failure prediction.
- Interpret model performance and identify potential areas for improvement.
- Demonstrate practical Data Science skills through an end-to-end project.

Technologies and Tools

The project uses Python and common Data Science tools, including:

- Python – Programming and data analysis.
- Jupyter Notebook – Interactive development and documentation.
- Pandas – Data manipulation and analysis.
- NumPy – Numerical computing.
- Matplotlib and Seaborn – Data visualization.
- Scikit-learn – Machine learning, model training, and evaluation.

Additional libraries may be used depending on the implementation in the notebook.

Project Workflow

The project follows a typical machine learning workflow:

1. Data Loading: Import the dataset and inspect its structure.
2. Data Exploration: Examine variables, data types, distributions, and relationships.
3. Data Preprocessing: Handle missing values, duplicates, categorical variables, and other preprocessing requirements where applicable.
4. Exploratory Data Analysis: Use visualizations and summary statistics to investigate patterns in the data.
5. Feature Preparation: Prepare the input features and target variable for modelling.
6. Model Development: Train a suitable machine learning classification model.
7. Model Evaluation: Assess model performance using appropriate evaluation metrics.
8. Interpretation: Review the results, limitations, and possible improvements.

How to Run the Project

You can explore or run the notebook using either Google Colab or a local Python environment.

Option 1: Google Colab

1. Download or open the project notebook.
2. Visit "Google Colab" (https://colab.research.google.com/).
3. Upload the ".ipynb" notebook.
4. Upload or connect the dataset if it is not already accessible.
5. Run the notebook cells sequentially.

Option 2: Local Environment

1. Clone the repository:
   
   git clone https://github.com/Bammy147/TS-Academy-Heart-Failure-Prediction-Capstone-Project-.git

2. Navigate into the project directory:
   
   cd TS-Academy-Heart-Failure-Prediction-Capstone-Project-

3. Install the required libraries:
   
   pip install pandas numpy matplotlib seaborn scikit-learn jupyter

4. Launch Jupyter Notebook:
   
   jupyter notebook

5. Open "group_38_bamijoko_olubunmi_daniel_corrected.ipynb" and execute the cells in order.

Important: The dataset file path and any additional dependencies must match the configuration used in the notebook.

Limitations and Responsible Use

This project is intended for educational and learning purposes. Its results should not be interpreted as a clinical diagnosis or used as a substitute for professional medical advice.

The predictive performance and reliability of any model depend on the quality, representativeness, and limitations of the dataset, as well as the methodology used to develop and evaluate the model.

Further validation on appropriate independent datasets would be necessary before considering any real-world clinical application.
